لفحص أي سهم: اضغط «افحص سهم» ← Run workflow ← اكتب الرمز (مثل ADBE) ← Run workflow.

النتيجة تظهر هنا بعد ٢–٣ دقائق. اسحب الصفحة للتحديث.

📘 كيف يعمل الماسح

١. الأسهم: كل الأسهم الأمريكية فوق ٢ مليار دولار (حوالي ١٥٠٠ سهم)، بدون البنوك والتأمين والتمويل التقليدي.

٢. الاستراتيجيات أولًا:

  1. ارتداد في اتجاه صاعد: سهم من أقوى ٣٠٪ أداءً خلال سنة، فوق متوسط ٢٠٠ يوم، نزل إلى المتوسط الذي احترمه تاريخيًا (اختبار ٥ سنوات).
  2. ما بعد الأرباح القوية (PEAD): قفزة ٥٪+ بحجم تداول مضاعف بعد أرباح فاقت التوقعات، ثم أول تراجع خلال ٢–٢٠ يومًا مع بقائه فوق قاع يوم القفزة.
  3. جودة بسعر مخفّض: أقل من قمته بـ ٢٠–٤٠٪، هامش ربح أو عائد على حقوق المساهمين ١٥٪+، تدفق نقدي حر موجب، إيرادات نامية، ومكرر أرباح معقول، وبدأ يستقر.

٣. ثم الفحص الشرعي على الناتج فقط: القطاع، الديون < ٣٠٪، النقد < ٣٠٪ من القيمة السوقية (معايير AAOIFI).
✅ = ضمن صناديق الشريعة HLAL أو SPUS · 🟡 = نجح بالفحص الأولي، أكّد نسبة الإيرادات المحرّمة (Zoya) قبل الشراء · ❌ = يُحذف.

قواعد الحماية: لا شراء قبل الأرباح بـ ٥ أيام (إلا PEAD) · الشراء على ٣ دفعات · حد أقصى ٨٪ للسهم · إذا كسر المنطقة بوضوح: أوقف التعزيز وراجع.

الأسعار: باليورو تقريبيًا (حسب سعر الصرف)، وبين قوسين بالدولار. البيانات من Yahoo Finance بسعر الإغلاق.

أداة تعليمية وليست نصيحة مالية. القرار النهائي لك دائمًا.
