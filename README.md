# الماسح الحلال

ماسح تعليمي لفرص الأسهم الأمريكية المتوافقة مع الشريعة. يعمل مجانًا على GitHub Actions.

- الصفحة: `https://<username>.github.io/scanner/`
- مسح يدوي / فحص سهم: تبويب **Actions** ← **scan** ← **Run workflow**
- قائمة صناديق الشريعة: `data/halal_etf.json` — أسهم Zoya غير المتوافقة: `data/zoya_block.txt`

أداة تعليمية وليست نصيحة مالية.
